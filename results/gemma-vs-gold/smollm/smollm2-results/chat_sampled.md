### [PASS] Write a Python function named is_even(n) that returns True if n is even.

```
Here's a Python function that checks if a number is even:

```python
def is_even(n):
    return n % 2 == 0
```

This function uses the modulus operator (`%`) to find the remainder of `n` divided by 2. If the remainder is 0, then `n` is even. Otherwise, it's odd.

You can use this function like this:

```python
print(is_even(10))  # Output: True
print(is_even(11))  # Output: False
```

### [PASS] Explain in two sentences why the sky is blue.

```
The sky is blue because of a phenomenon called Rayleigh scattering, which occurs when sunlight enters Earth's atmosphere and encounters tiny molecules of gases such as nitrogen and oxygen. These molecules scatter the shorter wavelengths of light, such as blue and violet, in all directions, while the longer wavelengths, like red and orange, are scattered in a more random manner. This scattering effect is responsible for the blue color of the sky, as it allows more blue light to reach our eyes than other wavelengths.
```
